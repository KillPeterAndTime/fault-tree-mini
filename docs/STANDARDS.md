# 标准对齐说明

语言 / Language: **简体中文** | [English](STANDARDS_EN.md)

本文档说明 FaultTree Mini 在图形符号和定量判定上遵循/参考的标准，便于在正式场合（评审、送审、培训）使用本工具时追溯依据。

## 一、图形符号

### 遵循的惯例画法

| 本工具符号 | 名称 | 依据 |
|---|---|---|
| 矩形 | 顶事件 / 中间事件 | IEC 61025:2006 Annex A；GB/T 4888-2009 §2；NUREG-0492 |
| 圆形 | 基本事件（底事件） | 同上 |
| 菱形 | 未展开事件（省略事件） | 同上 |
| 房形（五边形） | 房形事件（正常事件） | GB/T 4888-2009 正常事件符号；IEC 61025 house event |
| D 形（平底+半圆顶） | AND 门 | 惯例画法 |
| 盾形（凸拱顶+凹弧底） | OR 门 | 惯例画法 |
| 盾形 + k/n 标注 | 表决门 k/n | GB/T 4888-2009 表决门；IEC 61025 k-out-of-n |

### 关于符号刚性的说明

IEC 61025:2006 第 4 章明确指出符号可随用户偏好和软件实现有所变化，附录 A 为资料性（informative）而非规范性（normative）。本工具采用的是审查方普遍接受、各教材与商业工具通行的惯例画法。GB/T 4888-2009 对国内使用场景给出了名词术语和符号的权威定义，本工具的中文命名与之一致（顶事件/中间事件/底事件/基本事件/未探明事件/正常事件等）。

### 暂未实现的符号

- 转移符号（三角，转入/转出，用于大型树分页）
- 禁门 INHIBIT（需条件事件，椭圆符号）
- 顺序与门 PAND、异或门 XOR、非门 NOT（非连贯逻辑）
- 以上均在路线图中；如需分页大树，当前可拆分为多个项目文件

## 二、定量判定

### ARP4761A / AC 25.1309-1B 失效状态分级概率目标

顶事件可选失效状态等级，计算后自动对比每飞行小时概率目标：

| 失效状态等级 | 概率目标（每飞行小时） | 说明 |
|---|---|---|
| 灾难级 Catastrophic | ≤ 1×10⁻⁹ | 通常还要求无单点失效（单点失效检查属定性要求，需人工核查） |
| 危险级 Hazardous | ≤ 1×10⁻⁷ | |
| 较大级 Major | ≤ 1×10⁻⁵ | |
| 较小级 Minor | ≤ 1×10⁻³ | |
| 无安全影响 | 无定量要求 | |

**使用注意**：

1. 对比必须按**每飞行小时**口径——底事件概率输入时任务时间填 1，或直接输入每飞行小时概率
2. ARP4754A 定义研制流程与失效状态分类的分配（FHA→PSSA→SSA），ARP4761A 给出包括 FTA 在内的方法学；两者配合使用。本工具聚焦 4761A 的 FTA 方法环节
3. 审定实践中 FTA 通常作为 SSA 的定量支撑材料，最终可接受性由审定方认定。**本工具是辅助分析工具，不替代完整的安全性评估流程与审定信用**
