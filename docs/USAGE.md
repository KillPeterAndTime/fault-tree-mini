# 使用说明

语言 / Language: **简体中文** | [English](USAGE_EN.md)

## 1. 启动

用浏览器（推荐 Chrome / Edge）打开 `index.html` 即可，无需安装、无需联网、无需注册。数据全部保存在本地。

## 2. 界面布局

```
┌──────────┬──────────────────────────────┬──────────┐
│ 元件库    │           画布（SVG）          │  属性面板 │
│ 左侧     │   缩放控制条在右下角            │  右侧    │
└──────────┴──────────────────────────────┴──────────┘
状态栏：节点数 · 连接数 · 顶事件计算结果 · 提示消息
```

## 3. 画一棵树（三步）

1. **拖入节点**：从左侧元件库把符号拖到画布上。符号含义：

   | 符号 | 名称 | 用途 |
   |---|---|---|
   | 矩形 | 顶事件 / 中间事件 | 要分析的失效状态，概率由下级推导 |
   | 圆形 | 基本事件 | 不再分解的底事件，输入失效数据 |
   | 菱形 | 未展开事件 | 影响小或信息不足、暂不展开 |
   | 房形 | 房形事件 | 确定性状态（发生 q=1 / 不发生 q=0），用于边界条件与 what-if |
   | D 形 | AND 门 | 所有输入都发生输出才发生 |
   | 盾形 | OR 门 | 任一输入发生输出即发生 |
   | 盾形+k/n | 表决门 | n 个输入中至少 k 个发生 |

2. **连线**：拖动父节点**底部的小圆点**到子节点上即建立"父→子"逻辑连接。每个节点只有一个父节点（单父约束），连线时自动检测并阻止环路。同一父节点的多条连线自动走**直角总线式**（梳状），符合传统故障树画法。

3. **输入数据**：点击底事件，在右侧属性面板输入：
   - **失效率模式**：λ（/小时）+ 任务时间 t（小时），自动换算 q = 1−e^(−λt)；可选时间基准（/小时、/飞行小时、/飞行循环、/起降）
   - **直接概率模式**：输入 q（0~1）
   - 名称、失效模式描述可随时修改

## 4. 计算

点击工具栏 **计算** 按钮：

- OR 门：q = 1 − ∏(1−qᵢ)（独立事件概率求和）
- AND 门：q = ∏qᵢ（概率交集）
- 表决门：k/n 精确 Poisson-binomial（动态规划）
- 顶/中间事件：概率由下级逻辑推导（单输入直传、多输入按 OR 合并）
- **共用底事件**：同一底事件被多个门引用时，自动切换 ROBDD（二元决策图）精确求解——此时简单的独立性公式不成立，工具会处理正确

计算后每个节点上方显示 `P=` 概率徽标，状态栏显示顶事件概率。

### ARP4761A 分级判定

选中**顶事件**，在属性面板选择失效状态等级（灾难/危险/较大/较小/无安全影响）。计算后状态栏自动对比 AC 25.1309-1B 每飞行小时概率目标：

| 等级 | 目标（每飞行小时） |
|---|---|
| 灾难级 Catastrophic | ≤ 1×10⁻⁹ |
| 危险级 Hazardous | ≤ 1×10⁻⁷ |
| 较大级 Major | ≤ 1×10⁻⁵ |
| 较小级 Minor | ≤ 1×10⁻³ |

⚠ 对比时底事件概率须按**每飞行小时**口径输入（任务时间填 1）。判定通过显示绿色 ✓，超出显示红色 ✗。

## 5. 画布导航（大型树）

| 操作 | 方式 |
|---|---|
| 缩放 | 滚轮（以光标为中心）；右下角 −/＋ 按钮；`+` `-` `0` 键 |
| 适应视图（看整棵树） | 右下角"⤢ 适应"或按 `F` |
| 定位顶事件 | 右下角"⌖ 顶事件"或按 `T` |
| 平移 | 中键拖动（任意位置）或拖动空白处 |
| 自动布局 | 工具栏"自动布局"（布局后自动适应视图） |

大型树推荐流程：自动布局 → `F` 看全貌 → 滚轮放大查细节 → `T` 回顶事件。

## 6. 保存与打开

- `Ctrl+S` 或工具栏"保存"：保存为 `.fta.json` 项目文件。Chrome/Edge 下首次保存后再次保存直接写回原文件；其他浏览器下载副本
- `Ctrl+O` 或工具栏"打开"：打开项目继续编辑
- 未保存改动关闭页面前会本地自动暂存（localStorage），下次打开自动恢复

## 7. 导出图片

- **PNG**：2 倍清晰度，含全部节点与连线，自动裁剪边距
- **SVG**：矢量格式，可在 Visio / Illustrator / draw.io 中继续编辑

## 8. 常见问题

**Q：概率徽标没显示？** — 先点"计算"；只有计算过的节点才显示。

**Q：状态栏出现 ⚠ 提示？** — 常见：顶/中间事件无输入（按 0 处理）、顶/中间事件下有多个直接子节点（按 OR 合并）。按提示补上门即可。

**Q：计算出错"检测到循环逻辑"？** — 树里存在环（A→B→A），检查连线。

**Q：表决门 k/n 怎么设？** — 选中表决门，属性面板设 k（至少发生数）和 n（输入总数）。注意 n 应与实际输入数一致。

**Q：浏览器兼容性？** — 推荐 Chrome / Edge（支持写回原文件）。Firefox 可用但保存为下载副本。
